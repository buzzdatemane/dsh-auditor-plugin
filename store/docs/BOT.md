# Telegram sales bot (long polling)

Бот принимает заявки на **ручной аудит** и уведомляет владельца. Он работает
через `getUpdates` (long polling), поэтому **не нужен HTTPS, домен и webhook**.
Запускается на твоём ПК; пока ПК выключен, бот офлайн.

Сам бот создаётся вручную в **@BotFather** — это единственный шаг, который
нельзя автоматизировать.

## 1. Создать бота

1. Открой **@BotFather**.
2. `/newbot`.
3. Имя: `DSH Auditor`.
4. Username: например `dsh_auditor_<ник>_bot`.
5. Скопируй HTTP API token.

## 2. `.env`

```env
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_BOT_USERNAME=dsh_auditor_<ник>_bot
# опционально, но нужно для уведомлений и /issue:
TELEGRAM_OWNER_CHAT_ID=
DATA_DIR=./data
```

`TELEGRAM_OWNER_CHAT_ID` можно узнать так:

1. Запусти бота: `npm run bot`.
2. Напиши боту `/id`.
3. Он ответит chat id и user id.
4. Вставь свой chat id в `.env`.
5. Перезапусти бота.

## 3. Запуск

```powershell
cd store
npm run bot
```

При старте бот:

- вызывает `getMe` и печатает `https://t.me/<bot>`;
- удаляет webhook, чтобы работал long polling;
- начинает читать сообщения.

Остановка — `Ctrl+C`.

## 4. Команды покупателя

| Команда | Что делает |
|---|---|
| `/start` | приветствие и цены |
| `/buy audit` | создать заявку на аудит ($20) |
| `/status A-XXXXXX` | статус заявки |
| `/id` | показать chat id |
| `/help` | помощь |

Pro/Team/Lifetime пока отвечают «в разработке».

## 5. Команды владельца

| Команда | Что делает |
|---|---|
| `/orders` | последние заявки |
| `/issue A-XXXXXX` | отметить аудит выполненным, уведомить покупателя |
| `/reject A-XXXXXX` | отклонить заявку |

Владелец определяется по `TELEGRAM_OWNER_CHAT_ID`; остальные получают отказ.

## 6. Процесс

1. Покупатель нажимает `https://t.me/<bot>?start=site`.
2. `/buy audit` → заявка `A-XXXXXX`.
3. Тебе приходит уведомление в Telegram.
4. Ты согласуешь объём и присылаешь адрес кошелька.
5. После оплаты делаешь аудит и `/issue A-XXXXXX`.
6. Покупатель получает уведомление.

Оплата не автоматизирована: бот только принимает заявку и уведомляет.

## 7. Ограничения

- ПК должен быть включён.
- Нет HTTPS/вебхука — и не нужно для long polling.
- Один процесс на один bot token: Telegram не даёт запускать два polling
  одновременно.
- Не коммить `.env` и `data/bot-orders.json`.
- Для круглосуточной работы позже: VPS/Cloudflare Worker + webhook.
